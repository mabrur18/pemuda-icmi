- **2026-10-20**: Tahap 1 (Skema Sanity dan Studio) selesai: 9 tipe dokumen (`post`, `page`, `author`, `category`, `tag`, `event`, `publication`, `redirect`, `siteSettings`), 6 tipe objek (`seo`, `legacy`, `blockContent`, `youtube`, `callout`, `adSlot`), desk structure singleton & post ordering, Sanity TypeGen terintegrasi ke `apps/web/types/sanity.types.ts`, serta seed 14 dokumen (3 author, 5 kategori, 5 post artikel, 1 siteSettings) sukses diterbitkan di dataset `staging`.
- **2026-10-20**: Tahap 2 (Database Supabase & Server Client) selesai: SQL migrations (`subscribers`, `contact_messages`, `event_registrations`, `redirect_map`) dengan RLS aktif tanpa kebijakan publik, modul server-only Supabase client (`apps/web/lib/supabase/server.ts`), validasi Zod formulir & proteksi spam honeypot (`apps/web/lib/validation.ts`), dan pengujian otomatis (14 tests passed).
- **2026-10-20**: Tahap 3 (Design System & Komponen UI) selesai: Token CSS warna emerald/gold/dark mode, tipografi Next/font (Plus Jakarta Sans & Source Serif 4), komponen Button (min. 44px touch target), Chip, Container, Header sticky dengan drawer mobile, Footer 4-kolom, ThemeToggle (anti-flash script), ArticleCard (4 varian: large, standard, horizontal, compact), EventCard, PublicationCard, AuthorCard, dan halaman interaktif showcase `/design-system`. Build Next.js sukses 100%.
- **2026-10-20**: Tahap 4 (Halaman Publik Utama FR-101 sampai FR-107) selesai penuh: Seluruh rute publik diimplementasikan menggunakan data live Sanity staging. Terdiri dari Beranda (`/`), Indeks Berita dengan filter & paginasi (`/berita`), Halaman Artikel dengan Portable Text & TOC (`/berita/[slug]`), Arsip Kategori (`/kategori/[slug]`), Arsip Topik/Tag dengan conditional noindex (`/tag/[slug]`), Profil Penulis (`/penulis/[slug]`), Halaman Statis dinamis (`/[slug]`: Tentang Kami, Susunan Pengurus, Kebijakan Privasi), Pencarian cepat (`/cari`), Feed RSS 2.0 valid (`/rss.xml`), dan Halaman 404 (`/not-found`). Build Next.js menghasilkan 27 halaman statis (SSG), seluruh 9 rute diuji menghasilkan HTTP 200 OK, dan 404 handler menghasilkan HTTP 404. Lint, typecheck, dan unit test 100% lulus.
- **2026-10-20**: Tahap 5 (SEO Teknis & Webhook Revalidasi FR-401 sampai FR-404) selesai: `metadataBase` terpasang, generator metadata global dan dinamis (OpenGraph & Twitter Card), route dynamic OG Image (`/api/og`) berbasis Edge Runtime `next/og`, sitemap dinamis (`/sitemap.xml`) meng-query artikel, halaman, kategori, tag (hanya >= 3 artikel), dan penulis dari Sanity dengan `lastmod` dari `_updatedAt`, file `robots.txt` dengan pembatasan direktori privat, komponen dan schema builder JSON-LD (`NewsArticle`, `BreadcrumbList`, `WebSite`, `Organization`), serta endpoint On-Demand ISR webhook (`/api/revalidate`) dengan autentikasi secret/HMAC signature. Seluruh 19 unit test lulus 100%, kompilasi SSG 30 halaman sukses, dan endpoint diuji menghasilkan status HTTP yang tepat (200, 401 unauthenticated).
- **2026-10-20**: Tahap 6 (Integrasi AdSense & ads.txt FR-501 sampai FR-504) selesai: Script AdSense kondisional (`AdsenseScript`) yang hanya memuat script di environment produksi jika AdSense diaktifkan pada `siteSettings`, memiliki publisher ID valid berawalan `pub-`, serta mencegah injeksi pada rute pencarian (`/cari`), rute api, dan halaman noindex/404. Komponen `AdSlot` mengalokasikan ruang tetap (min-height: inArticle 280px, belowArticle 250px, sidebar 600px, inFeed 120px) dengan `useRef` guard untuk mencegah duplikasi eksekusi `window.adsbygoogle.push({})` dan mengeliminasi Cumulative Layout Shift (CLS). Injeksi otomatis slot iklan di artikel berita setelah paragraf ke-3 di Portable Text renderer jika tidak ada slot iklan manual. Berkas standar `apps/web/public/ads.txt` disiapkan dengan placeholder standar `pub-XXXXXXXXXXXXXXXX` dan komentar instruksi yang jelas. Seluruh 28 unit tests lulus (termasuk 9 unit test khusus AdSense & ads.txt), lint dan typecheck 100% lulus.
- **2026-10-20**: Tahap 7 (Formulir & Data Pengunjung FR-601 sampai FR-603) selesai: Modul pembatasan laju IP (`apps/web/lib/rate-limit.ts`) dengan sliding window 5 req/min, layanan email (`apps/web/lib/email.ts`) dengan mock email provider bawaan & templating HTML branded, Route Handler buletin dengan double opt-in (`/api/newsletter`, `/api/newsletter/confirm`, `/api/newsletter/unsubscribe`) dengan proteksi anti-enumerasi email, Route Handler formulir kontak (`/api/contact`) dengan penangkal spam otomatis honeypot (`website_hp`), Route Handler pendaftaran kegiatan (`/api/events/register`) dengan pencegahan duplikasi email, komponen interaktif `NewsletterForm` dan `ContactForm` dengan label di atas, galat inline, dan persetujuan privasi wajib terhubung ke `/kebijakan-privasi`, halaman publik `/kontak` serta halaman status `/buletin/konfirmasi`. Seluruh 46 unit test lulus 100%, kompilasi Next.js 37 halaman sukses, dan endpoint diuji pada live server menghasilkan respons yang presisi (200, 400 honeypot/invalid, 307 redirect).
